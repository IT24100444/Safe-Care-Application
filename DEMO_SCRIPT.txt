[1:00 — ARCHITECTURE]
(show assets/architecture_diagram.png)
Let us walk through the architecture. When a user submits a query, it first enters our Security Checkpoint node, which scrubs PII like Sri Lankan NIC numbers, blocks prompt injection attacks, and intercepts medical emergencies. Once cleared, the safe_care_orchestrator delegates requests to two specialized sub-agents: facility_care_specialist for district and facility resolution, and doctor_schedule_specialist for doctor availability. Both agents execute tools via our Safe Care MCP Server, which communicates directly with the Node.js Express backend. For write actions like booking, a Human Confirmation pause requires explicit user approval before execution.
(pause)
